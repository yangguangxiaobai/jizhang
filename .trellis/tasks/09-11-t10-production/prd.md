# T10 生产部署与验收

> 父任务:`.trellis/tasks/09-11-web-pwa`
> 依赖:**T1..T9 全部完成**(需要完整应用才能验收)。
> ⚠️ 本任务需要**用户提供 VPS 访问方式与域名**,并在关键步骤与用户确认后再操作线上环境。

## Goal

把应用部署到用户的 VPS + 域名上,与用户已有的 Nginx/Caddy 反代共存,启用 HTTPS 与备份,
并逐条实测父任务的验收标准 AC1–AC11。

用户价值:这一步之前所有功能都只存在于开发机上。这是唯一让用户真正用起来的环节。

## Background

- 部署设计见父任务 `design.md` §7(单容器、只绑 `127.0.0.1:8081`、多阶段 Dockerfile、备份)
- 用户环境(已确认):Docker Compose;VPS 上**已有 Nginx 或 Caddy 在跑**,需要共存;
  VPS 规格 1核1G 或 2核2G
- ⚠️ **风险**:配置失误可能影响用户 VPS 上**其它已在运行的站点**。所有反代改动必须
  是**新增**配置,不得修改或替换现有配置

## Requirements

### R1 部署前置确认(必须先与用户确认)

- VPS 的 SSH 访问方式
- 域名,以及域名解析是否已指向该 VPS
- 当前反代是 Nginx 还是 Caddy,配置文件位置
- 是否已有 Docker 与 compose plugin
- 现有站点列表(确认不会互相影响)
- **在这些信息确认前,不执行任何线上改动**

### R2 镜像构建与分发

- 在**本地**构建镜像(1核1G VPS 上构建会 OOM,父任务 D6)
- 分发方式(择一,与用户确认):
  - 推送到镜像仓库(GHCR / Docker Hub)后在 VPS 拉取
  - `docker save` + `scp` + `docker load`
- 镜像打**带日期的 tag**(如 `jizhang:2026-09-11`)以便回滚(design.md §9)

### R3 部署

- 在 VPS 上创建独立目录(如 `/opt/jizhang`),放 `docker-compose.yml` 与 `.env`
- `.env` 权限收紧(如 `chmod 600`),含 `JIZHANG_USERNAME`、`SESSION_TTL_DAYS`、`TRUST_PROXY=true`
- `docker compose up -d`
- 数据卷挂载到宿主机目录,确认容器重建后数据仍在(AC9)
- 容器设置资源限制(如 `mem_limit`),避免影响宿主其它服务
- 用 `set-password` CLI 初始化密码(不在 `.env` 放明文)

### R4 反代共存(最高风险操作)

- **只新增**一段 server block / site 配置,指向 `127.0.0.1:8081`
- 不修改、不替换访问者已有的任何配置
- 操作前先备份现有反代配置目录
- 配置语法校验(`nginx -t` 或 `caddy validate`)通过后再 reload
- HTTPS 证书由现有反代统一管理(复用其已有的 ACME 配置)
- 验证用户**其它站点仍正常**(这是本任务的硬性验收项)

### R5 备份

- 备份脚本:用 `sqlite3 jizhang.db ".backup '...'"`,**不能直接 `cp`**
  (WAL 模式下直接复制可能拿到不一致的快照 —— design.md §7.4)
- 容器内执行备份到挂载目录,宿主机可见
- 定时任务(宿主 cron 或 compose 中的 sidecar),保留最近 N 天
- **备份可恢复性必须实测**:恢复一次并确认数据完整(只测"生成了文件"不算)

## Technical Notes

- **顺序很重要**:先在本地验证镜像与 compose(T1 已做过容器冒烟),
  再改线上。**反代改动放最后**,且改前备份、改后立即验证其它站点
- `TRUST_PROXY=true` 必须设置,否则在反代后拿到的客户端 IP 恒为 127.0.0.1,
  且 `Secure` Cookie 判定可能出错
- Cookie 的 `Secure` 属性依赖正确的协议识别;若反代未下发 `X-Forwarded-Proto`,
  Fastify 会认为连接是 http,导致 Cookie 不生效。这是反代后最常见的坑
- 1核1G 场景:可给容器设 `mem_limit: 256m`;SQLite 的 WAL 文件会占用额外磁盘,
  注意磁盘余量
- 备份保留策略与磁盘容量要匹配:单用户账本体积极小,保留 30 天完全无压力
