# iPhone 记账精简与核心预算闭环交付

## Goal
交付可在 iPhone Safari / 添加到主屏幕后使用的 Web PWA，不需要 Mac 或 Apple 开发者账号。核心是每月工资按模板分配预算，日常记账正确影响对应模块和结余池。

## Approval
用户在完整范围摘要之后回复“开始”（2026-09-12），明确批准建任务与实施。本任务不增加待确认的产品范围。

## Scope
- 删除 PIN 应用锁整套入口、锁屏、状态与仅服务它的代码；保留服务端账户登录、会话与 CSRF 保护。
- 保留已有账单、模板、工资、退款、回收站、导入导出、备份、统计等数据和能力；不删除已有配色改动。
- 修复模板外分类支出在预算中消失的问题。已存在工资周期内的模板外支出显示为零预算模块，其超支纳入结余池；退款、编辑、删除和历史回看使用同一口径。
- 修复工资修改接口金额/日期与分配快照脱节。金额变更必须同时提供总和匹配的明确分配，不静默覆盖微调；日期与分配快照一起变更且原子提交。
- 完整验证模板→工资→记账→预算，以及修改/退款/删除恢复、同月追加工资、跨周期结余。
- 改善与验证 iPhone 窄屏、触摸区域、输入、浏览器/独立模式、在线优先和登录体验；补充可操作的交付与部署说明。

## Acceptance
- [x] A1 PIN 功能从源码与构建产物移除；携带旧 PIN 浏览器存储也不阻止使用；认证仍有效。
- [x] A2 浏览器中设置模板、录入工资、预览并保存分配，模块总额逐分等于工资，刷新后持久化。
- [x] A3 支出、分类修改、退款、删除、恢复实时反映到正确模块；模板外支出不消失。
- [x] A4 同月工资合并；跨周期历史、结余池与趋势一致，未分配分类也被计入。
- [x] A5 工资金额更新要么与完整匹配分配原子成功，要么全量拒绝；日期更新同步周期；错误请求不留下部分变更。
- [x] A6 iPhone 尺寸浏览器主流程可操作，无横向溢出，控件≥44px、输入≥16px，有安全区；添加到主屏幕与联网要求清晰。
- [x] A7 lint、typecheck、全部单测/接口测试、构建与静态审计通过；用隔离环境跑实际浏览器主流程并记录引擎及局限。
- [x] A8 README、用户使用/部署说明、验收记录与最终源码一致；交付可运行构建，不声称未执行的真机或线上验收。

> 逐项证据见 `implement.md` §A1–A8 核对。**唯一未完成的仍是部署**（`09-11-t10-production`，

## Out of Scope
原生 iOS、App Store、推送服务、新的离线账本同步、多用户；未经另行授权访问或修改真实 VPS、删除业务数据。
