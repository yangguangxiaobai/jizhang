# Android 品牌与记账体验：设备验收清单

状态：NOT RUN。此文件是待执行清单，不代表已装机、已部署或已通过。

目标：Android API26+ 与支持 APK 的 HarmonyOS 4；HarmonyOS 5/6 原生客户端不在本轮。使用隔离测试账本/服务，不向生产新增测试交易。每条记录设备、系统、桌面、APK SHA-256、后端版本、观察结果与截图/视频证据。

## 1. 名称与图标（品牌子任务）

- [ ] 全新安装只出现一个桌面入口，名称 Yansuu1记账，默认第6款橙色图标。
- [ ] 设置与外观提供六张预览，顺序对应用户上传顺序，当前选择明确，点击已选项不重复切换。
- [ ] 逐一切换1→2→3→4→5→6，桌面最终只有一个入口，均可启动；设置内显示与实际启用组件一致。
- [ ] 快速连续点击不同图标、重复当前选择、切换后立即退后台，不丢入口或长期出现多个入口，不丢当前服务地址/会话。
- [ ] 重启进程/手机后保留选择；应用覆盖升级后保留选择，旧版首次升级使用默认6；证书不匹配不能冒称可覆盖升级。
- [ ] 验证旧版已固定桌面图标/快捷方式能否继续启动；缓存更新延迟/需要重新固定的桌面限制如实记录，不以设置预览当桌面证据。
- [ ] 圆形/圆角/其他系统掩模不裁掉核心账本和人民币符号；浅深壁纸可辨识，无额外白边框造成主体过小。
- [ ] 在API26顺序组件切换和API33+批量切换（若采用）各验一次；切换失败仍可启动且可重试。

## 2. 首页（首页子任务）

- [ ] 不再显示可操作月份下拉；收支标签和数值始终对应服务端当前月。
- [ ] 账单页月份、常驻账户、类型及其他已应用条件筛选保持可用。
- [ ] 首页各账户名/余额与 balances.items 一一对应，不出现固定微信/银行卡假分配；总额与接口totalBalanceCents一致。
- [ ] 覆盖0/1/2/多账户、同名但不同ID账户、长账户名、零/负/大金额；不重名合并、不挤压金额、不截掉可访问账户。
- [ ] 隐藏金额同时遮蔽总额和全部明细；滚动/展开也不能泄漏金额。
- [ ] 首页刷新期间保留数据时明确注明旧结果；余额首次失败不显示伪0，重试可恢复。
- [ ] 余额成功但预算/分类/周期提醒失败，能按约定显示独立余额或局部失败，不伪造数据。
- [ ] 修改初始余额/记收入支出/工资/转账/软删除及恢复交易后刷新，首页与服务端权威余额同步，不在Android重算账务。

## 3. 账单详情卡片（交互子任务）

- [ ] 首页最近账单和账单列表点击均打开有遮罩的底部圆角卡片，能看到原页面背景，不是全屏页包一张卡。
- [ ] 返回键、点遮罩、下滑、关闭按钮均只关闭详情，不误退来源Tab。
- [ ] 在账单页选历史月、单账户、类型、第2页并滚动后开关详情，筛选/页码/滚动位置保留。
- [ ] 切换所看账单、详情重试后，旧请求成功/失败/结束不会覆盖最新账单。
- [ ] 网络失败提供卡片内重试；会话过期回登录，不显示过期账单为可编辑成功。
- [ ] 编辑与退款成功后来源数据明确刷新并保留筛选；不匹配原筛选的新退款不被强塞进支出列表。
- [ ] 保存取消/有草稿返回符合放弃确认，不因编辑关闭顺带丢失原列表状态。

## 4. 从支出记录退款（交互子任务）

- [ ] 原支出卡片有记录退款按钮；普通收入/退款记录不能错误作为原支出预设。
- [ ] 打开后为新的退款收入草稿，关联原支出明确显示；金额留空由用户确认，日期默认今天。
- [ ] 原账户仍可用时默认到账账户为原账户；原账户已不可用时要求明确选择，不悄悄改到第一个账户。
- [ ] 分类为可用收入叶子分类且可见；无可用分类时说明原因，不把原支出的支出分类发送为收入。
- [ ] 金额/日期/到账账户可改；全额、部分、多次退款分别验证；不额外添加当前后端不存在的累计封顶政策。
- [ ] 保存产生新 type=1/isRefund=true 账单并关联原ID，原支出金额/type不被改写。
- [ ] 失败保持金额/日期/账户/关联等草稿；取消后再新建普通账单不会残留退款预设。
- [ ] 现有普通收入、支出、编辑、多原账单关联退款流程不回归；软删除或无法读取原支出的服务端拒绝能看见提示。

## 5. 数字输入、系统键盘与顶部错误（交互子任务）

- [ ] 记账时金额与自定义键盘同时可见，数字、小数点、删除实时更新金额，无滚到下面才能输入的问题。
- [ ] 分类/账户/日期/备注/标签可完整访问；小屏/横屏/大字体时有合理回退，不挤掉键盘或必要字段。
- [ ] 备注/标签系统键盘弹起时不叠两套键盘，不遮金额；收起后自定义键盘可恢复，草稿不丢，保存可触达。
- [ ] 顶部和底部保存如同时保留，使用一致校验/提交状态；双击不会并发重复提交。超时重试的既有无幂等限制如实保留，不宣称网络层恰好一次。
- [ ] 空金额/无分类账户/日期错误/服务端保存失败均在可见顶部提示，不需滚到底部；提示不被详情/选择器窗口盖住。
- [ ] 普通设置下提示约4500ms自动消失，可手动关闭；相同错误再次触发重新完整计时，旧计时器不关闭新提示。
- [ ] TalkBack朗读错误并提供关闭操作；无障碍建议超时可延长，不能为了严格4500ms而破坏可访问性。
- [ ] 错误自动消失后保留输入与必要的字段提示/加载重试；401仍走统一认证失效处理。
